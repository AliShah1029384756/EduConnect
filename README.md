# EduConnect

EduConnect is an educational web platform project built with Node.js, Express, and frontend assets (HTML/CSS/JavaScript).  
The goal is to provide a practical structure for learning full-stack fundamentals through real project organization.

## Overview

This project demonstrates:
- Server setup with Express
- Route-based architecture
- Frontend integration from the `public` directory
- Utility/helper modularization in `utils`
- Practical project structure for CS students and beginner developers
